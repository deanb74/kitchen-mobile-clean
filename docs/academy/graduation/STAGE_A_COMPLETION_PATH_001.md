## 5. Completion Dependencies

The evidence order matters because each later assessment relies on the scope established by the preceding one:

```text
CONSTITUTIONAL_SCOPE
        ↓
FORMATION_EVIDENCE_SCOPE
        ↓
VALIDATION_COVERAGE_AND_REPEATABILITY
```

- Constitutional evidence provides the foundational scope and boundaries for interpreting what Academy formation must preserve.
- Formation evidence provides the Academy-specific behaviours, journeys, runtime achievements, and unresolved conditions that validation must cover.
- Validation evidence provides the repeatability and coverage information needed to assess whether the formation scope has been evidenced beyond bounded scenarios.

The current evidence records do not create the unresolved evidence in any layer. A later assessment can only rely on evidence that is directly recorded within the relevant scope.
