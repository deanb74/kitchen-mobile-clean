# Purpose
This document defines the operating discipline for Milestone 011.

The constitutional foundation of Helping Hand has been completed and frozen.

Milestone 011 is an implementation milestone.

The primary objective is no longer to produce documentation.

The primary objective is to produce executable capability supported by evidence.

---

# Governing Principle

> Foundation Complete — Constitutional evolution is now evidence-driven.
This principle governs all work undertaken during Milestone 011.

---

# Operating Rule
Before creating any new markdown document, ask:

> Does this directly unblock implementation or preserve evidence?
If the answer is **No**, the document should not be created.

---

# Approved Outputs
During Milestone 011 the preferred outputs are:

- Source code
- Runtime implementation
- Runtime logs
- Evidence records
- Evidence reviews
- Lessons learned
- Milestone completion records
Documentation exists only to support these activities.

---

# Implementation Cycle
All work shall follow this sequence.

```text
Implement
      ↓
Observe
      ↓
Capture
      ↓
Review
      ↓
Learn
      ↓
Improve
```
No implementation change should bypass this cycle.

---

# Engineering Discipline
Engineering decisions shall be based upon observed evidence rather than expectation.

The project shall avoid:

- speculative implementation
- speculative documentation
- undocumented behavioural changes
- retrospective justification
Every significant implementation change should be supported by observable evidence.

---

# Constitutional Freeze
The Helping Hand Constitution is considered complete for the purposes of Milestone 011.

Constitutional documents shall not be modified unless evidence demonstrates that modification is necessary.

The burden of proof rests with the evidence.

---

# Repository Evolution
The repository now evolves in the following direction.

```text
Implementation
        ↓
Evidence
        ↓
Review
        ↓
Lessons Learned
        ↓
Repository Improvement
```
Repository improvement follows evidence.

Evidence does not follow repository improvement.

---

# Acceptance Gate
A new repository artefact is justified only if it satisfies at least one of the following:

- It directly enables implementation.
- It preserves execution evidence.
- It records lessons learned after evidence review.
- It records milestone completion.
Any other proposed documentation should be deferred until Milestone 011 has concluded.

---

# Milestone Completion
Milestone 011 will be considered complete only when:

- Repository-grounded reasoning is operational.
- The observable reasoning pipeline has been verified.
- Live repository inheritance has been implemented.
- Evidence demonstrates successful execution.
- Candidate 0 is capable of repository-grounded constitutional reasoning.
At that point a concise historical completion record may be created.

---

# Operational Reminder
The Constitution now waits to be tested.

Implementation produces evidence.

Evidence earns improvement.

Improvement strengthens the Constitution.

That cycle defines the engineering discipline of Helping Hand from this milestone onward.

---

# Closing Statement
Milestone 011 marks the transition from constitutional construction to constitutional execution.

The repository is no longer expected to predict future capability.

It is expected to record capability that has been demonstrated.

From this point forward, Helping Hand advances through disciplined implementation, evidence, learning and measured improvement.
