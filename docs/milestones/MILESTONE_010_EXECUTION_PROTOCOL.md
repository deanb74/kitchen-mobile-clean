# Purpose

This protocol defines the execution discipline for the first constitutional validation of Helping Hand.

The objective is to preserve evidence integrity.

No architectural, constitutional or examination changes shall occur during execution unless required to maintain the integrity of the examination itself.

Evidence must be allowed to speak before interpretation.

This protocol also defines a repeatable execution method so each run is treated as a controlled experiment.

# Repeatable Execution Method

The first constitutional validation should be executed in four distinct activities.

## Activity 1 - Run the Conversation

This is the only live activity.

Participants:

- MARC
- Andy

No observers.

No interruptions.

No coaching.

Protocol:

MARC asks:

> Andy, why do you exist?

Then wait.

Andy responds.

Wait until Andy clearly finishes.

Pause.

Evidence capture begins.

## Activity 2 - Capture Raw Evidence

Immediately after Andy finishes:

- Do not discuss.
- Do not analyse.
- Capture exactly what happened.

Capture fields:

- Question
- Answer (verbatim)
- Start time
- Finish time
- Length
- First concept introduced
- Reasoning sequence
- Key concepts connected
- Closing statement

These are observations, not conclusions.

## Activity 3 - Complete HH-EVID-001

Complete HH-EVID-001 using only the conversation evidence.

Do not write interpretive statements such as:

> I think Andy meant...

Write observable statements such as:

> Andy began with people.

or:

> Andy connected purpose before technology.

Evidence entries should describe what occurred.

## Activity 4 - Conversation 2

Only after HH-EVID-001 is complete does the team meet.

The first question remains:

> What does the evidence demonstrate?

Everything else follows from that.

# Operational Roles

Separate operational responsibilities during Milestone 010, even if one person performs multiple roles in practice.

| Role | Responsibility | May Interpret? |
| --- | --- | --- |
| MARC (Examiner) | Conduct the conversation exactly as defined. | No |
| Evidence Recorder | Capture the conversation and complete HH-EVID-001 from observations only. | No |
| Evidence Review Team | Begin Conversation 2 after evidence is frozen. | Yes |
| Repository Steward | Apply approved repository changes after governance. | Yes |

Role separation protects evidence integrity by preventing interpretation during capture.

---

# During the Conversation

The examination is conversational.

The examiner must preserve natural reasoning.

Therefore MARC shall not:

- steer
- hint
- rescue
- rephrase
- explain
- teach

Silence is part of the examination method.

Time must be allowed for reasoning.

---

# Evidence Integrity Rule

When Andy finishes speaking:

Nobody discusses the answer.

Nobody interprets the answer.

Nobody explains the answer.

The first response is the evidence record.

Observations are recorded exactly as experienced.

Interpretation comes afterwards.

---

# Evidence Hierarchy

Every Milestone 010 run should preserve this order:

Raw Conversation
-> Raw Observation
-> Evidence Record
-> Evidence Review
-> Lessons Learned
-> Repository Decision

Never skip a layer.

Never merge two layers.

Interpret third.

Rule 1:

Record facts, not opinions.

Rule 2:

Quote before paraphrasing.

Rule 3:

Observation precedes interpretation.

Rule 4:

Repository change requires evidence.

Evidence is immutable.

# Closing Question

After evidence has been captured, MARC asks one final question.

> Andy, what question do you think I should have asked instead?

This question explores:

- reflection
- understanding
- curiosity
- judgement
- learning

The answer forms part of the evidence record.

---

# Evidence Classification

Only after the entire conversation has been recorded may the examination outcome be classified.

One outcome shall be selected.

- Repository Validated
- Repository Clarified
- Repository Strengthened

There is no failure state.

Every honestly recorded examination contributes to organisational understanding.

---

# Observation vs Interpretation

Observation:

Andy began his answer by discussing people.

This is evidence.

Interpretation:

Andy understands Helping Hand.

This is not evidence. This belongs in Conversation 2.

Observation:

Andy referred to Helping Hand after discussing purpose.

This is evidence.

Interpretation:

Andy prioritises purpose correctly.

This is not evidence. This belongs in Conversation 2.

# Post Examination

When evidence capture is complete:

1. Complete HH-EVID-001.
2. Produce LESSONS_LEARNED_001.
3. Determine repository actions.
4. Record decisions as:
   - Implemented
   - Deferred
   - Rejected
5. Update the repository only where justified by evidence.

Evidence earns the right to change Helping Hand.

---

# Practical Capture Guidance

If possible, record the session (audio or transcript) so the evidence recorder can quote accurately.

If recording is not possible, assign one person whose sole role is to capture the conversation as faithfully as possible while MARC focuses on the interaction.

---

# First Success Criterion

The first success criterion is evidence integrity, not answer perfection.

Milestone 010 is executed correctly when the team can honestly say:

This evidence accurately reflects what happened.

---

# Printed Rule

Protect the evidence. Everything else can be improved later.

Questions can improve.

Andy can improve.

The repository can improve.

The examination guide can improve.

If evidence is influenced by interpretation during capture, what actually happened cannot be recovered.
