# Validation Evidence

This directory contains evidence and protocols for validating Digital Colleagues as colleagues, not merely as software systems.

## Distinction

- Engineering evidence answers: does the implementation work?
- Human evidence answers: does the colleague work for people?

## Decision rule

Engineers validate software. People validate Digital Colleagues. Helping Hand validates inheritance. Only when all three agree does a capability become part of the foundation.

This is a decision process for earned universality. A capability is not inherited because it is reusable, or because one team likes it. It is inherited because the evidence has earned that right.

## Evidence families

- Human validation sessions
- Human validation results
- Engineering validation records
