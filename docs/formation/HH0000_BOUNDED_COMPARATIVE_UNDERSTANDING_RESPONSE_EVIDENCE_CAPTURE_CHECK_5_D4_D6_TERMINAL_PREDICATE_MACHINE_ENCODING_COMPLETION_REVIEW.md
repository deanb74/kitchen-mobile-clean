## 3. Existing D3-V2 Expressiveness Boundary

`NormalizedStructuralFactV2` has no field for:

1. argument count;
2. exact or finite normalized argument literal value;
3. whether every argument satisfies a selector;
4. callback argument identity and static-resolution status;
5. callback transitive terminal-classification status;
6. same-file helper export/return/recursion/transitive-validity status;
7. operation-scenario call, mutation, failure, or assertion cardinalities;
8. assertion operation/matcher identity and expected value;
9. assertion membership in the same callback and post-dominance of a specific operation set;
10. cross-record identity/equality relations among first copy, second copy, persisted baseline, response capture, receipt capture, checker input, and injected failure.

`PredicateV2` therefore has no corresponding selectors. `argumentConstraints` can constrain only a listed index's broad provenance and data-label sets. It cannot require that an index exists, reject an additional index, select a literal value, quantify over every argument, or relate two records.

`ProbeValidity=AUTHORISED` is selectable but not independently sufficient. Its documented derivation says that all D6 selectors, assertions, cardinalities, and non-escape relations must pass. Those constituent facts and relations are not represented. Treating the summary value as self-validating would move the missing matcher into hidden normalization logic.

## 9. Overlap and Order-Independence Test

The existing prohibited-first algorithm remains valid:

```text
evaluate every D5 prohibited predicate
-> any prohibited match: FAIL and report every family
-> otherwise evaluate every D4/D6 terminal predicate
-> zero terminal matches: FAIL UNKNOWN
-> multiple terminal matches: FAIL AMBIGUOUS
-> exactly one terminal match: accept that one classification
```

Adding order, first-match priority, or operation-name precedence cannot resolve the missing facts. For the decisive literal pair, every current predicate sees identical data regardless of order.
