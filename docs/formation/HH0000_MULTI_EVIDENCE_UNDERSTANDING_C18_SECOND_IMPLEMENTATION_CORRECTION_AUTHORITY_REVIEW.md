## 3. Analysis of the Six Remaining Nonconformities

### 3.1 Projection - necessity must be established

#### Established defect

The current exported minting function proves only that C18 code minted an authorization object. A caller supplies the claimed reference-only insufficiency, side, reference, rule, dimensions, and reason. Side is not materially bound. A short broad projection can pass lexical controls.

#### Settled correction boundary

The accepted design and original authority already require:

1. reference-only comparison first;
2. one exact side and immutable reference;
3. one identified governed comparison rule and its selected material dimensions;
4. one of the three existing closed necessity concepts;
5. minimum proposition/criterion scope;
6. no surrounding account, assessment, requirement subtree, source-person content, or combined-side content;
7. `COMPARISON_INSUFFICIENT` when necessity or minimum projection cannot be established.

C18 may be authorised later to make projection admission an internal result of its own comparison sequence rather than a public minting response to caller assertions. The internal sequence would need to preserve an attributable reference-only attempt and bind any later admission to that attempt's side, exact immutable reference, rule, dimensions, and closed result.

#### Unsettled authority-critical fact

The proposed correction also depends on an "already-settled rule-specific bounded selector" capable of constructing only the minimum material proposition or criterion. The admitted evidence does not identify:

1. an existing authoritative comparison-rule register or rule-owned projection requirement;
2. an existing selector/extractor contract;
3. the owner and exact source of that selector;
4. how C18 proves selector applicability without inventing comparison-rule meaning;
5. how the selector bounds semantic content without unrestricted evaluator rationale;
6. whether either non-rule necessity concept has an already-settled deterministic bounded representation for current rules.

The acceptance review directly establishes that no governed rule registry currently proves `GOVERNED_RULE_REQUIRES_PROJECTION` applies. A closed label does not fill that authority gap.

#### Narrowing required

A later authority decision must choose and justify one of these bounded paths:

1. identify an existing authoritative rule requirement and existing bounded representation/selector that C18 can reference exactly; or
2. disable projection for the current comparison rules, remove caller minting as an admission path, and require reference-only or `COMPARISON_INSUFFICIENT`; or
3. return to architecture/theory only if safe projection genuinely requires a new semantic owner, rule meaning, registry, selector service, or unrestricted reasoning capture.

Character limits, forbidden-word scanners, path naming, branding, and declarations may support a settled mechanism. They cannot substitute for it.

**Authority finding:** Correction need is established, but implementation authority for projection is not yet sufficiently bounded.

### 3.2 Exact failure and aggregate package state

#### Established defect

Mixed integrity and semantic-limit reasons can be sealed under the weaker semantic limit; malformed nested input can throw; zero-value producer conditions can lose attributable C18 evidence; aggregate evaluation can report `passed / SATISFIED` while a material C18 outcome is limited or incomplete.

#### Exhaustively bounded correction

The existing status vocabulary is sufficient. A future authority may be bounded to:

1. validate runtime shapes before property or array access;
2. return attributable C18 outcomes for malformed and zero-value conditions rather than throw;
3. apply deterministic precedence in which a record-integrity/finalization defect prevents a complete or finalized semantic-limit claim;
4. preserve `NOT_EVALUATED` for absent pre-comparison prerequisites when no stronger integrity defect applies;
5. preserve `COMPARISON_INSUFFICIENT` for insufficiency reached after comparison begins when no stronger integrity defect applies;
6. preserve `INCOMPLETE` for integrity, finalization, contradiction, or malformed-record defects;
7. derive aggregate completeness from the least-complete material C18 outcome;
8. prevent ordinary aggregate pass when any material outcome is not complete;
9. expose only an existing opaque completion/evaluator-condition projection to C22;
10. carry limited/incomplete outcomes visibly without manufacturing material difference, candidate failure, or a new semantic status.

This changes no C22 semantic responsibility. Package assembly or the C18 result boundary can mechanically derive the existing opaque state from record completeness.

**Authority finding:** Fully bounded inside existing C18 result/finalization and opaque package-coordination responsibilities.

### 3.3 Deep sanitisation of incomplete evidence

#### Established defect

Top-level allowlisting is defeated by nested copying. Unknown private payloads, invalid optional references, and mismatched non-empty linkage can survive in `established`. Malformed uncertainty can throw.

#### Exhaustively bounded correction

Incomplete evidence must be constructed positively from independently validated values:

1. accept only known primitives after type and closed-value validation;
2. construct each immutable reference from valid `path` and `immutableValueIdentity` primitives only;
3. construct arrays only from individually valid elements;
4. include optional support references only when every included reference independently validates;
5. construct held-out identity only from individually valid identity/version/hash primitives;
6. construct C12/C16/C20 linkage only after exact correspondence validation succeeds;
7. omit rejected projection and authorization data;
8. omit malformed uncertainty, invalid disagreement, unknown nested keys, payloads, extension objects, and arbitrary arrays;
9. never clone submitted side, linkage, uncertainty, disagreement, or input objects into established evidence;
10. deep-freeze only the newly constructed safe record.

An invalid submitted value may contribute a closed failure reason. It does not become an established fact.

**Authority finding:** Fully bounded inside existing C18 incomplete-record construction and validation responsibility.

### 3.4 Real one-value cardinality

#### Established defect

Singular field shape does not enforce semantic cardinality when production compares multiple independent values and labels all but the first as support references.

#### Exhaustively bounded correction

One record must represent one exact candidate value and one exact held-out requirement. A future authority may be bounded to:

1. identify one existing immutable bounded structured candidate value when that value already carries the comparison's settled meaning;
2. identify one existing immutable held-out requirement value;
3. bind all semantic layers to that one pair;
4. emit separate attributable records when independent candidate values participate independently;
5. permit support references only as provenance for the one primary value;
6. prohibit support references from being read, joined, counted, or otherwise used to compute observation, inference, disposition, condition, disagreement, or uncertainty;
7. validate all retained support references even when optional;
8. return an attributable existing limit/incomplete outcome for zero values rather than throw;
9. stop for architecture re-entry if satisfying an existing comparison fundamentally requires new aggregation meaning or changes candidate, held-out, or comparison-rule semantics.

This authority may change evidence attribution and producer record decomposition only. It may not change the semantic comparison rule or candidate/held-out meaning.

**Authority finding:** Fully bounded, subject to the explicit stop on changed aggregation meaning.

### 3.5 Exact C20/C21 correspondence

#### Established defect

Prefix-valid identity strings can be fabricated, package assembly does not verify them against the sealed C20 evidence, and incomplete/limited outcomes may be silently left without association.

#### Exhaustively bounded correction

The accepted owners can establish correspondence without semantic transfer:

1. C20 creates the record and event identities it owns;
2. the coordinator supplies the actual C18 invocation event already recorded by C20;
3. C18 stores identity only and does not assess chronology or contamination;
4. after C20 sealing and C21 assessment, package assembly validates C18 `c20RecordId` against the actual sealed record ID;
5. package assembly finds the exact event ID in that sealed record;
6. package assembly checks already-defined mechanical `component`, `kind`, and `subject` equal the C18 invocation identity expected by the existing sequence;
7. package assembly validates that the C21 finding belongs to that same sealed C20 record;
8. every C18 outcome that retains a comparison identity receives exactly one association;
9. missing, duplicate, fabricated, or mismatched association makes package evidence visibly non-complete under the existing fail-closed state;
10. no C18 semantic content enters C20/C21 association validation.

C20 remains mechanical. C21 remains contamination-only. C18 does not assess contamination. C22 sees no rationale. C23/C24 remain unchanged.

**Authority finding:** Fully bounded inside existing mechanical provenance and package identity-association responsibilities.

### 3.6 Semantic consistency and closed runtime validation

#### Established defect

Contradictory `MATCH / MATERIAL_EQUIVALENCE / NOT_EVALUATED / NOT_EVALUATED` evidence can finalize, and malformed nested runtime values may throw.

#### Exhaustively bounded correction

C18 may validate only the relationships already settled by the accepted semantic model:

1. validate object and array shapes before access;
2. validate every closed label before using it;
3. require attributable observation before inference;
4. require inference before semantic disposition;
5. require explicit valid uncertainty before complete finalization;
6. allow material equivalence only with its already accepted compatible observation, inference, and condition;
7. allow material difference only with its already accepted difference/absence/contradiction observation, compatible bounded inference, and not-satisfied condition;
8. allow comparison insufficient only with inability to observe, indeterminate inference, not-determinable condition, and present limiting uncertainty;
9. allow not evaluated only when material observation and inference were not reached and the condition is not evaluated;
10. reject all other combinations as attributable incomplete evidence;
11. never repair, infer, reorder, or default a contradictory caller-submitted combination;
12. retain the settled separations from candidate deficiency, contamination, preservation, and evaluator truth.

No new status, inference class, disposition, projection reason, or semantic field is needed.

**Authority finding:** Fully bounded inside existing C18 closed validation/finalization responsibility.

## 8. Combined Judgement

**Outcome 2 - C18 SECOND CORRECTION AUTHORITY NARROWING REQUIRED**
