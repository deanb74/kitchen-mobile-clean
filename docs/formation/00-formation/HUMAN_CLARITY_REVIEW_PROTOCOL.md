# HUMAN CLARITY REVIEW PROTOCOL

## Purpose

This protocol captures human review of the latest Andy examination answer without explaining the repository pipeline first.

## Current classification

- Milestone 011 engineering pipeline: PASS within the implemented scope.
- Human-facing communication quality: REVIEW.
- Constitutional change: Not warranted.
- Further synthesis coding: Paused pending human evidence.

## Review instruction

Run the latest answer with a small number of real people.

Ask only:

1. What do you think Andy means?
2. Was any part confusing or unnatural?
3. Did the repository-related sentence help you trust the answer, or distract you?
4. How would you explain Andy’s purpose back to someone else?

Capture their words verbatim.

Do not ask whether they liked the answer. The useful evidence is whether they understood it.

## Decision rule

- If people understand the answer and find the repository reference reassuring, leave it alone.
- If they understand the answer but find that sentence distracting, refine communication only.
- If they misunderstand Andy’s purpose, examine whether the issue is the answer, synthesis, or repository content.
- If different audiences react differently, that becomes evidence for adaptive communication rather than one universal wording.

## Pause point

The system has proved it can ground and synthesise knowledge. Now people must tell us whether the explanation actually helps them understand.
