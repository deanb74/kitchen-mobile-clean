# Formation Inheritance Architecture

## Architecture summary

Formation inheritance is now represented by a separate runtime path from ordinary repository retrieval.

## Boundary

- Repository retrieval remains responsible for factual, architectural, theoretical and organisational knowledge.
- Formation inheritance is a separate ordered curriculum path that governs Andy's developmental sequence.

## Runtime behaviour

- Andy exposes a formation register via the runtime.
- Formation stages are evaluated through explicit prerequisites and evidence requirements.
- A formation stage is only marked inherited after evidence is provided and the stage is recorded into memory.
- Formation status is not inferred from file existence, indexing or ordinary retrieval.
