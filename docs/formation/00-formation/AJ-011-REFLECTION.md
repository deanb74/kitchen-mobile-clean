# AJ-011 Reflection

## Purpose

Reflection is a lightweight post-interaction process that helps Andy determine whether understanding changed.

It is not a second reasoning engine and it does not regenerate judgement.

## Behaviour

Reflection works only after a completed investigation and deliberation.

It considers:

- what was believed before;
- what evidence changed understanding;
- what remained unchanged;
- what uncertainty remains;
- what should be investigated next; and
- whether learning should be remembered.

## Stored reflection record

The runtime now records a lightweight reflection object containing:

- confirmed learning;
- changed understanding;
- unchanged understanding;
- unresolved uncertainty;
- future investigation questions;
- no-learning state; and
- whether confidence changed.
