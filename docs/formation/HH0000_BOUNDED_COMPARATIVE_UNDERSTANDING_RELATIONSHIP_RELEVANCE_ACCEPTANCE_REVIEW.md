## 9. Material Remaining Defect

Fresh source inspection identifies another relevance and completeness failure beyond the two new examples.

Comparison grouping can add a separate `apparent-disagreement` for each differing governed metadata category. A supplied set may therefore contain status, date, scope, or state disagreements at the same time.

After forming those relationships, the implementation uses:

```ts
const disagreement = relationships.find((relationship) => relationship.kind === "apparent-disagreement");
```

All later relevance and unresolved treatment uses only that first relationship:

1. `hasRelevantDirectRelationship` is computed only for the first disagreement;
2. qualification is tied only to that disagreement;
3. possible-supersession formation is tied only to that disagreement;
4. `unresolved-relationship` formation is tied only to that disagreement;
5. the sole human-decision question is tied only to that disagreement.

Later apparent disagreements retain their own relationship-level uncertainty and become labelled Inferences in the final loop. They do not receive an independent relationship-relevance assessment, unresolved-relationship consequence, or human-decision-boundary assessment.

This means one resolved first disagreement can coexist with a separate later unresolved disagreement that is never independently returned to the human. Conversely, an unresolved first disagreement can produce one generic human question while later material disagreements remain unexamined as distinct decision boundaries.

The governing formation boundary requires relevant Observations to be compared across the supplied set rather than allowing first-match processing to determine the conclusion. The human-decision boundary permits omission only where an attributable explicit relationship and its relevant scope resolve the requested relationship. Processing only the first formed disagreement does not establish that condition for later disagreements.

The correction Authority expressly withheld general multi-disagreement redesign, and correction Evidence accurately records that limitation. The correction is therefore Authority-conformant but insufficient for the complete bounded implementation claim.

**Material defect:** `MULTIPLE FORMED DISAGREEMENTS ARE NOT INDEPENDENTLY EVALUATED FOR RELEVANCE, UNRESOLVED CONSEQUENCE, AND HUMAN DECISION OWNERSHIP`.
