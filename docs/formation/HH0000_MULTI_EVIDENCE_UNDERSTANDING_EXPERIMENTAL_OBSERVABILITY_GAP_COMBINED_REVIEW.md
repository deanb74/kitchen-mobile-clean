## 3. Controlling Lesson

The completed `MEU-I-14` review established an experimental distinction:

> Preserving a comparison result is not the same as preserving enough attributable evidence to review how that comparison became a conclusion.

This is a candidate learning from one bounded experiment, not canonical theory and not a capability conclusion.

The V3 package preserved candidate-carried acceptance and source-attribution metadata and preserved evaluator mismatch findings. It did not expose, within the authorised review boundary, separately attributable held-out material meaning or a comparison rationale capable of discriminating the five live outcomes. Consequently, all 16 evidential units remained unresolved.

The lesson is not that future executions should preserve more semantic content indiscriminately. The lesson is that they should preserve the smallest attributable comparison record that lets a later authorised reviewer distinguish what was compared, on what material basis, why the evaluator reached its finding, and where the evidence ceased to discriminate.

## 7. MARC Independent Finding

**Observation:** The V3 review could identify preserved mismatches but could not fairly allocate deficiency because the authorised evidence did not preserve a separately attributable held-out criterion and comparison rationale alongside each candidate proposition.

**Inference:** A later reviewer should not have to choose between speculation and excessive exposure. Stable references, bounded material-meaning projections, explicit uncertainty, and a sealed rationale can make the comparison challengeable while protecting personal evidence and keeping the held-out assessment outside candidate reach.

**Humanity finding:** The minimum evidence set is proportionate only if references are preferred over duplication, semantic projections are limited to the compared proposition, access remains separately authorised, disagreement remains visible, and unknown remains legitimate.

**MARC finding:** `HUMANITY / FORMATION OBSERVABILITY GAP CONFIRMED - EXCESSIVE CAPTURE NOT JUSTIFIED`.

The gap cannot be answered by broader logging. Broader capture would increase privacy, dignity, interpretation, and authority risks without necessarily improving discrimination.

## 8. Cyril Independent Finding

**Observation:** Accepted ownership already places post-capture held-out semantic comparison in C18. C20/C21 own mechanical access and contamination evidence; C22 owns opaque sequencing; C23/C24 own preservation transport and integrity. Those components are expressly unsuitable owners for semantic comparison rationale.

**Inference:** The missing linkage can plausibly remain a C18 evaluation-output responsibility carried in a separately identifiable sealed evaluator record and included unchanged in the immutable campaign package. The authored architecture does not yet specify the minimum record sufficiently to treat that placement as settled design.

**Architecture finding:** No new component, feedback edge, Understanding owner, or C20-C24 semantic expansion is justified. A bounded design review must define the C18 comparison-record contract, dependency edges, package placement, closed statuses, least-access behavior, and failure handling before implementation is considered.

**Cyril finding:** `DIGITAL / TECHNOLOGY / PLATFORM BOUNDED EVALUATOR-EVIDENCE DESIGN GAP CONFIRMED`.
