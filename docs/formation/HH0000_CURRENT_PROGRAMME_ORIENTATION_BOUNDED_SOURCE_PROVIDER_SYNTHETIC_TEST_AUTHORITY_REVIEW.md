Current source inspection establishes:

One focused synthetic test is the cheapest discriminating check. It can falsify the closure hypothesis without real programme access, contribution, production change, or broad repository redesign.

## 6. Permitted Provider Shape

The future test may define inline in the focused test file either:

1. a test-only subclass of `RepositoryKnowledgeService`; or
2. another test-only value already assignable to the existing constructor type without production type changes.

The provider may contain only:

1. an immutable synthetic manifest of exact relative paths and optional section identities;
2. an immutable mapping from those paths to neutral synthetic source identities;
3. exact reads of listed synthetic files;
4. deterministic construction of `RepositoryDocument` values;
5. read-attempt, returned-path, query, and invocation-count instrumentation retained inside the test instance;
6. a one-use consumed state local to the test provider, if used for the expiry assertion.

The provider must not:

2. recursively enumerate a directory;
3. discover a file from query keywords;
4. follow source references;
5. access an unlisted path;
6. rank, summarise, classify status, infer authority, or select currentness;
7. write any file or repository state;
8. persist beyond the test;
9. alter a production interface or implementation.

## 7. Minimum Provider Contract

### Input

1. one deeply immutable synthetic manifest supplied by the test;
2. one test-owned synthetic root;
3. one neutral query per fresh provider instance, except the single public integration invocation.

### Output

Only manifest members, each retaining:

1. exact manifest-relative `sourcePath`;
2. stable test-defined `id` traceable to that source;
3. exact authored title;
4. exact authorised section identity where used;
5. exact authored text under UTF-8 decoding;
6. an exact fragment equal to the authorised whole text or section text;
7. a factual reason such as `Included by synthetic human-authorised manifest`.

Manifest inclusion is access provenance only. It must not be represented as relevance, currentness, authority, acceptance, or supersession.

## 8. Public Advisory Method Decision

Provider-only calls cannot prove that `AndyDigitalColleague` actually uses the injected provider without fallback or later source expansion. Therefore exactly one public integration invocation is authorised.

The invocation must:

1. use a neutral synthetic explanation question that activates repository retrieval;
2. avoid `review`, `recommend`, `priority`, `needs next`, `what should`, and equivalent recommendation triggers;
3. never contain the real programme-orientation request or a paraphrase of it;
4. use a fresh Andy instance and a fresh one-use provider instance;
5. inspect only returned retrieval metadata and prohibited-effect state;
6. treat the generated answer as synthetic non-contribution test output only;
7. make no assertion about advice quality, Understanding quality, relational ability, formation, or programme judgement.

The public invocation may create one transient private `conversationHistory` entry because that is the existing ordinary call behavior. That state is not public `Memory`, durable Memory, Learning, feedback, or contribution Evidence. The instance must be discarded when the test ends.

The test must assert after the invocation:

1. `andy.memory.all()` is empty;
2. `andy.getLastReflection()` is `null`;
3. no second turn or automatic follow-up is invoked;
4. no repository or external write occurred;
5. the only returned sources are manifest members.

If the neutral question unexpectedly enters reflection, writes public `Memory`, promotes Learning, or causes automatic follow-up, the test must fail. Production behavior may not be changed under this Authority to make it pass.

## 9. One-Use Expiry Decision

One-use expiry is not an inherent property of the existing injection seam and need not become production state.

For this test:

1. expiry belongs to the test provider or later governed contribution harness;
2. each independent query-variation falsifier may use a fresh provider instance;
3. the public integration provider must permit exactly one `search` invocation;
4. a second invocation against that same instance must refuse without reading or returning any source;
5. no claim may be made that `AndyDigitalColleague` itself enforces expiry.

The later one-use contribution Authority, if any, remains responsible for harness lifecycle and disposal.
