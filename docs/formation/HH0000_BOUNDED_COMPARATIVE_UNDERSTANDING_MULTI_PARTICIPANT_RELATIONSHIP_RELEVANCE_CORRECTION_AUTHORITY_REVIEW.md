## 6. Independent Defect Confirmation

Current private formation:

1. forms an `apparent-disagreement` from all structurally valid Observations carrying different authored values in one governed metadata category;
2. derives the complete distinct participating source-ID set from that disagreement's Observation IDs;
3. asks whether any explicit relationship passes the existing exact relevance helper;
4. suppresses possible supersession, unresolved relationship, unresolved uncertainty, and the human-decision question when any relationship returns relevant.

The existing helper:

1. resolves the disagreement's participating records;
2. compares exact relationship subject and object against supplied title, source ID, and complete source path;
3. requires each identity to map uniquely;
4. requires two distinct participating source IDs.

It does not require those two IDs to equal the complete participating source-ID set.

For A/B/C status disagreement plus `A supersedes B`, exact identity resolution returns A and B. Both participate, so current relevance returns true even though C is uncovered. The whole A/B/C unresolved boundary is then suppressed.

**Defect classification:** `LOCAL PRIVATE COMPLETE-COVERAGE OMISSION`.

## 7. Default Hypothesis Decision

The default hypothesis is accepted with one necessary precision:

> One explicit authored relationship may suppress unresolved consequences for one apparent disagreement only when the exact distinct source IDs resolved from that relationship equal the complete distinct source-ID set participating in that disagreement.

Formally:

```text
coveredSourceIds(relationship, disagreement)
    = sorted(unique(exact subject/object source-ID resolutions))

participatingSourceIds(disagreement)
    = sorted(unique(source IDs from the disagreement's Observation IDs))

relationship may suppress unresolved consequences
    iff
coveredSourceIds == participatingSourceIds
```

All existing exact identity failure conditions remain mandatory. Set equality is an additional relevance condition, not a replacement identity rule.

Because one parsed relationship contains exactly one subject and one object, its exact covered set contains at most two source IDs. It cannot equal an A/B/C participating set.

## 8. Why Proper-Subset Coverage Must Fail Closed

An exact relationship covering A and B remains attributable Evidence. It may describe A relative to B. It does not establish:

1. C's relationship to A;
2. C's relationship to B;
3. which position governs across A, B, and C;
4. whether C qualifies, supersedes, is superseded, amends, is amended, replaces, or is replaced by another participant;
5. whether the complete disagreement is resolved.

Suppressing the A/B/C unresolved boundary from only A/B Evidence would silently promote partial relationship Evidence into complete resolution.

The correction must therefore preserve the explicit relationship Observation while retaining the independently formed A/B/C unresolved relationship, uncertainty, applicable Inferences, and canonical A/B/C human-decision boundary.

The current private model forms one unresolved relationship for the complete disagreement group. This Authority does not authorise splitting it into a new C-only relationship or changing relationship types.

## 9. Collective Relationship Coverage Decision

The current private provenance can establish exact subject and object IDs for each binary relationship. It cannot safely establish that a collection of relationships resolves a complete multi-participant disagreement merely because the union of their covered IDs equals the participating set.

For example, all of these collections have union `{A, B, C}`:

```text
A supersedes B
B supersedes C
```

```text
A supersedes B
C supersedes A
```

```text
A supersedes B
A supersedes C
```

Union equality alone cannot distinguish a chain, cycle, conflicting orientation, common governing record, amendment network, or complete pairwise account. Selecting among those meanings would require a separately governed composition rule concerning direction, consistency, conflict, scope, and possibly transitivity.

No such relationship-composition rule exists in the current bounded private model. The current helper returns relevance for one relationship at a time. The model has no formed collective-resolution object, directed coverage contract, conflict detector, transitive rule, or attributable decision identifier.

Therefore:

```text
union of several binary relationship source-ID sets
    == complete participant set

does not imply

complete disagreement resolution
```

Even when a neutral fixture supplies `A supersedes B` and `A supersedes C`, this correction must retain unresolved treatment for the A/B/C disagreement. Suppression would require interpreting the collection as one complete governing account, which this Authority does not license.

**Collective-coverage finding:** `EXISTING PRIVATE PROVENANCE IS INSUFFICIENT FOR MULTI-RELATIONSHIP COMPOSITION WITHOUT NEW SEMANTIC GOVERNANCE`.

This insufficiency does not block the conservative local correction. It blocks only collective suppression. The safe correction is to require complete coverage by one exact relationship and otherwise fail closed.
