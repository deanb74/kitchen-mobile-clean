## 9. Conversation Support, Response Generation, Response Recording, Observation, and Assessment

These are distinct meanings.

| Term | Meaning within this boundary | Not established by it |
| --- | --- | --- |
| Conversation support | A human-led interaction context in which questions can be asked and an actual response can be received | A new runtime capability or runner |
| Response generation | Producing text as an output of a runtime or model | Andy’s actual observed response |
| Response recording | Preserving the actual response supplied during the conversation | Interpretation, assessment, or capability proof |
| Observation | Human attention to what was said, what was understood, and what remained unknown | A pass/fail or acceptance decision |
| Assessment | Judgement against criteria or a formal decision about performance | Part of the First Observation boundary |

The required separation is:

```text
CONVERSATION_SUPPORT != RESPONSE_GENERATION
RESPONSE_GENERATION != RESPONSE_RECORDING
RESPONSE_RECORDING != OBSERVATION
OBSERVATION != ASSESSMENT
```
