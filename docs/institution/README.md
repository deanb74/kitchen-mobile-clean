## Library Relationship

Helping Hand now works across five reinforcing institutional questions:

- Theory: What is true?
- Governance: How is truth protected?
- Formation: How is it taught?
- Evidence: Can it be proven?
- Institution: How does Helping Hand itself evolve?

These are not separate projects.

They are one institutional learning system viewed through different responsibilities.
