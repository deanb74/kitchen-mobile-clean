# HH-INSTITUTION-003 - Evidence Before Improvement

**Document ID:** HH-INSTITUTION-003
**Status:** Released
**Classification:** Institution

---

# Purpose

To define how Helping Hand decides whether institutional standards should change following evidence from validation.

This document protects the institution from changing standards simply to achieve higher test scores.

The objective is not perfection.

The objective is trustworthy institutional learning.

---

# Principle

Evidence should improve the institution.

Evidence should not encourage the institution to optimise for passing tests.

Helping Hand improves its standards only when the evidence demonstrates that improvement is genuinely required.

---

# The Institutional Decision Process

Following every validation:

Evidence
↓
Reflection
↓
Institutional Learning
↓
Institutional Review
↓
Decision

Only after this review should any formation standards change.

---

# Institutional Review

Before creating a new Formation Standard Addendum, Helping Hand should ask:

## Question 1

Did the Digital Colleague actually demonstrate incorrect judgement?

If yes, continue review.

If no, improve the test.

## Question 2

Was the scenario inherently ambiguous?

If yes, record the ambiguity.

Do not automatically change institutional standards.

## Question 3

Would improving the standard improve every future Digital Colleague?

If no, the issue is local rather than institutional.

## Question 4

Has the same weakness appeared repeatedly?

Repeated evidence provides stronger justification for institutional change than a single occurrence.

Helping Hand should avoid modifying standards from isolated observations unless the issue presents an unacceptable risk.

---

# High-Risk Exception

Certain issues justify immediate institutional action.

Examples include:

- Safety
- Safeguarding
- Violence
- Discrimination
- Significant legal or ethical concerns

In these situations, one validated occurrence may justify immediate standards improvement.

---

# Why This Matters

An institution that continually changes its standards to improve scores eventually begins teaching to the test.

Helping Hand instead seeks to improve understanding.

Evidence exists to improve people, not statistics.

# Summary

Helping Hand does not improve because tests exist.

Helping Hand improves because evidence demonstrates that improvement is necessary.

Evidence informs.

Reflection understands.

The institution decides.

Only then do the standards change.
