## Founder Completion Guidance

Completing this document is not a design exercise.

The founders are not being asked to define Andy's future role, grant him authority, or decide what Helping Hand should build next.

They are being asked to describe the current institutional reality honestly — so that when Andy is asked *"Where are you now?"*, the institution has already answered that question for itself.

If the founders find a section difficult to complete, that difficulty is information. It means the institution does not yet have sufficient clarity on that dimension — and UJ-HUM-014 should wait until it does.

**Three things to remember while completing this document:**

1. Candidate understanding should be confirmed, not promoted. If something is in PD-001 as candidate, confirming it here does not make it settled — it makes it the current working understanding for this specific exercise.

2. Unknowns should be named, not resolved. If the founders genuinely do not know something, the correct answer is to name it as unknown. Andy needs permission to not know what the institution does not know.

3. This document describes today. It is not a permanent statement about Andy's role, Helping Hand's direction, or the organisation's future. It will be updated as the evidence programme advances.

## What Stage 1 is

**[FROM EVIDENCE]**

Stage 1 is internal practical validation.

Source: `docs/handovers/VOLUME_VIII_EXIT_CRITERIA.md`

> *"Validate the inheritance model through Candidate 0 — Andy. Reuse the same validated structure for Annie. Reuse the same validated structure for live hospitality venue execution."*

The operating cycle for Stage 1:

```
Capability
    ↓
Human Interaction
    ↓
Human Outcome Evidence (HOER)
    ↓
Operational Proof
    ↓
Institutional Review
    ↓
Institutional Decision
    ↓
Inherited Organisational Learning
    ↓
Future Capability
```

Stage 1 ends when: the organisation has demonstrated that the inheritance model works, that Andy can validate it, and that Annie can be built from it.

Stage 1 has not yet produced this evidence. It is active.
