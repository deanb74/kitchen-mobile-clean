# Purpose

The Strategic Insights Register (SIR) preserves significant strategic insights, opportunities and long-term observations that Helping Hand intentionally chooses to retain before they become strategy, roadmap commitments or implementation work.

Its purpose is not to create work.

Its purpose is to ensure that valuable organisational thinking is never lost simply because today is not the right day to act upon it.

The register exists to transform founder insight into organisational understanding.

---

# Principles

Nothing is invented twice.

Everything is inherited.

Capture before creating.

Discover before deciding.

Understand before commitment.

Strategy follows understanding.

Implementation follows strategy.

Evidence governs implementation.

Do something once.

Benefit everywhere.

Helping Hand remembers before it plans.

---

# Scope

The Strategic Insights Register is **not**:

- a roadmap
- an engineering backlog
- a task list
- a project plan
- a wishlist

The Strategic Insights Register is:

- a repository of future organisational opportunity
- a record of strategic thinking
- a bridge between founder insight and organisational strategy

# Status Lifecycle

| Status | Meaning |
|----------|----------|
| Captured | Insight has been recorded. |
| Under Review | Being assessed against repository and strategy. |
| Deferred | Reviewed and consciously set aside pending a stated condition or review trigger. Distinct from Archived (permanent) and Captured (not yet reviewed). |
| Approved | Agreed in principle. |
| Planned | Dependencies understood and implementation scheduled. |
| In Progress | Active work underway. |
| Implemented | Successfully completed and adopted. |
| Inherited | Capability has become part of Helping Hand's standard inheritance model. |
| Superseded | Replaced by a better understanding. |
| Archived | Retained for historical reference. |

# Review Cadence

A Strategic Insights Repository Review should normally occur:

- at volume completion;
- when 10 or more new SIR entries have been added since the previous review;
- when an entry is proposed for elevation from Captured to Approved.

These are triggers, not mandatory bureaucracy. The Founding Board may initiate a review earlier where evidence or strategic importance justifies it.

The purpose of each review is to determine whether organisational understanding has reached the point where an insight should become strategy, architecture, implementation, or inheritance — or remain intentionally deferred.

---

# Success Measure

A successful Strategic Insights Register allows Helping Hand to answer:

- Have we already recognised this opportunity?
- Why did we preserve it?
- What would it take to make it real?
- What should happen first?
- Is now the right time?
- Is there now a better way?

The objective is organisational understanding rather than organisational memory.
