# Engineering Principles Library

This library records engineering principles that govern how contributors conduct work.

Institution documents govern how Helping Hand learns as an organisation.

Engineering principles govern how engineers gather evidence, make decisions, and protect truth during execution.

Canonical references, ownership and status are governed by the Document Register:

- [Document Register](../architecture/DOCUMENT_REGISTER.md)

This library index is for navigation only.

> **Documentation enters maintenance mode.**

Documentation is not considered finished.

Documentation growth now follows evidence rather than ideas.

---

## Identifier Taxonomy

The following identifier taxonomy is a frozen convention for navigation and interpretation.

| Prefix | Purpose | Changes When |
| --- | --- | --- |
| CON | Constitution | Extremely rarely |
| THEORY | Understanding and models | Evidence requires it |
| GOV | Governance | Process changes |
| INST | Institutional learning | Evidence changes institutional behaviour |
| EP | Engineering Principles | Engineering culture evolves |
| ED | Engineering Directives | Current engineering priorities change |
| EED | Engineering Execution Directives | Immediate operational execution priority changes |
| OEP | Operational Execution Playbooks | Execution process improves |
| PROOF | Validation programmes | New capabilities require proof |
| HOER | Human Outcome Evidence Records | Every significant live interaction |

Authoritative status, ownership and lifecycle remain governed by the Document Register.
