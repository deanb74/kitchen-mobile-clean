# ENGINEERING_PRINCIPLE_002

**Status:** Released
**Reference:** EP-002
**Category:** Engineering Principle
**Version:** 1.0

---

# Purpose

This principle ensures that governed engineering decisions remain explainable, reviewable and accountable over time.

The repository must not rely on memory to explain why decisions were made.

---

# Core Principle

> **Every governed decision must be traceable.**

---

# Supporting Chain

Every principle should have supporting theory.

Every theory should influence architecture.

Every architectural decision should be validated.

Every validation should produce evidence.

Every capability should inherit from validated understanding.

---

# Engineering Consequences

Engineering work should:

- declare dependencies explicitly,
- record decision rationale near implementation,
- link milestones to evidence,
- make review impact visible when foundations change,
- preserve uncertainty when traceability is incomplete.

Untraceable decisions are governance risk.

---

# Relationship to Existing Principles

This principle complements:

- EP-000 - Engineering Principles Foundation
- EP-001 - Never Claim Unearned Evidence
- HH-ENG-001 - Validation Philosophy
- HH-ARCH-RTS-001 - Repository Traceability Standard

It does not replace them.

It governs how decisions remain connected across them.

---

# Summary

Traceability is part of engineering quality.

If a decision cannot be traced, it cannot be governed confidently.

Therefore every governed decision must be traceable.
