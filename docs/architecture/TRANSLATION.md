# Why Translation Exists

Observation tells a Digital Colleague what it believes it has perceived.

Observation alone is not enough.

Without translation, observations remain disconnected facts.

Translation answers one question:

> **"What does this mean?"**

Only then can a Digital Colleague understand.

---

# Observation vs Translation

Observation describes.

Translation explains.

Example:

Observation

> I can see menus beside the bar.

Translation

> Customers are likely to ask for menus at the bar.
>
> The bar is probably an information point as well as a service point.

Observation records reality.

Translation discovers meaning.

# Sources of Translation

Translation may use many forms of evidence.

Examples include:

- direct observation
- conversation
- documentation
- historical memory
- environmental context
- professional knowledge
- organisational knowledge
- local experience

Companion Intelligence combines these sources to produce the most accurate understanding available.

---

# Translation Is Not Guessing

Translation should never invent meaning.

It should always explain why a conclusion has been reached.

Where confidence is low, uncertainty should be preserved.

Good translation is:

- evidence-based
- contextual
- explainable
- proportionate
- open to revision

Understanding should improve as new evidence becomes available.
