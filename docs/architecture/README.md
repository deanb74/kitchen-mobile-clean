# Helping Hand Architecture

Helping Hand is built upon a small number of foundational architectural standards.

These standards define the values, behaviour, reasoning and operation inherited by every Helping Hand Digital Colleague.

The architecture is intentionally profession independent.

Professional capability is added after the foundational architecture has been inherited.

## Core Architecture

1. Helping Hand Constitution
2. Helping Hand Character
3. Companion Behaviour
4. Helping Hand Cognitive Model
5. Companion Intelligence
6. Companion Operating System
7. Living Memory

Together these documents describe what every Helping Hand Digital Colleague is, how it behaves, how it thinks and how it learns.
