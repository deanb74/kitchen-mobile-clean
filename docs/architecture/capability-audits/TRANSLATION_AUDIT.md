# Translation Capability Audit

**Capability:** Translation

**Date:** 14 July 2026

---

# Purpose

Determine whether Translation belongs within the Companion Operating System (COS).

---

# Description

Translation converts observation into understanding.

It answers:

> **"What does this mean?"**

Observation alone cannot produce understanding.

Translation connects evidence with meaning.

---

# Scope

Translation is responsible for:

- discovering meaning
- preserving evidence
- connecting observations
- building contextual understanding
- preparing judgement

Translation is not responsible for:

- observation
- decision making
- action
- reflection
