# Helping Hand Platform Roadmap

## Purpose

Helping Hand is building the infrastructure required for trusted Digital Colleagues to work safely, reliably and commercially.

Annie is the first Digital Colleague.

The platform must eventually support:
- Multiple venues
- Multiple organisations
- Multiple industries
- Multiple Digital Colleagues
- Secure knowledge flow between local colleagues, industry HQs and Helping Hand HQ

---

# Phase 1 – First Road

Goal:
Make Annie usable in a controlled test environment.

Includes:
- Mobile app
- Existing Railway backend
- PostgreSQL database
- Authentication
- Basic venue/site structure
- Secure API calls
- Logging
- Environment variables
- Backups

---

# Phase 2 – Secure Site

Goal:
Protect the platform before wider testing.

Includes:
- Role-based access control
- Multi-tenant data separation
- Audit logs
- Encrypted secrets
- Secure file storage
- GDPR review
- Data retention policy
- Incident response process

---

# Phase 3 – Commercial Access

Goal:
Allow real customers to discover, request and onboard Helping Hand.

Includes:
- Website
- Waitlist / demo request form
- Product pages
- Pricing model
- Contact form
- Customer onboarding flow
- Terms and privacy policy

---

# Phase 4 – Scale

Goal:
Support many venues, organisations and industries.

Includes:
- Organisation HQ layer
- Industry HQ layer
- Helping Hand HQ layer
- Knowledge promotion workflow
- Monitoring and alerts
- Usage billing
- Support workflows

---

# Engineering Rule

Build only the infrastructure required for the next validated step.

Do not build motorways before the first builders need a road.
