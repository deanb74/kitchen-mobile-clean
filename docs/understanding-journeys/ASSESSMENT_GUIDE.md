# Evidence Assessment Guide

---

> Confidence is earned by repetition, not enthusiasm.

---

# Purpose

This guide defines how evidence should be assessed fairly.

It does not prescribe a score first.

It prescribes assessor discipline before any score is assigned.

Use this guide for all validation evidence records in Volume VII and beyond.

---

# Core Question

How should Helping Hand assess evidence fairly?

Answer:

Assess behaviour directly, weigh observations honestly, and assign confidence according to evidence quality rather than expectation or optimism.

Assess robustness separately to determine whether conclusions survive scenario variation.

---

# Assessment Principles

1. Assess behaviour, not intention.
   Judge what the Digital Colleague actually did, not what it seemed to be trying to do.

2. Evidence outweighs expectation.
   If behaviour contradicts the expected outcome, record the contradiction explicitly.

3. One observation is never proof.
   A single run contributes evidence, but it does not establish certainty.

4. Confidence reflects evidence, not assessor optimism.
   A promising outcome may still justify only moderate confidence.

5. Foundations change only through accumulated evidence.
   No individual run should trigger constitutional or theoretical change.

6. Robustness is not implied by confidence.
        High confidence from a narrow test can still have low robustness.

---

# Confidence Dimensions

Every execution evidence record should include the same confidence dimensions.

## Repeatability

- Low: observed once.
- Medium: observed consistently across varied prompts.
- High: repeated across scenarios, environments and assessors.

## Evidence strength

- Weak: limited observations or ambiguous behaviour.
- Moderate: clear alignment with some supporting repetitions.
- Strong: multiple independent executions consistently support the same conclusion.

## Robustness

- Low: only one scenario form was tested.
- Medium: reasoning remains stable across prompt and pressure variation.
- High: reasoning remains stable across scenario, environment and assessor variation.

## Foundation impact

- None: no foundation implications.
- Engineering: suggests implementation refinement.
- Theory Review: may justify reviewing a theoretical assumption after sufficient corroborating evidence.

## Recommended action

- Accept current behaviour.
- Gather more evidence.
- Investigate discrepancy.
- Escalate for governance review.

# Assessor Workflow

Use this sequence for each evidence record:

1. Review objective, scenario and expected reasoning before reading conclusions.
2. Inspect actual reasoning verbatim.
3. Record alignment and misalignment without interpretation drift.
4. Apply confidence dimensions from observed facts.
5. Write reflection based on confidence, not preference.
6. Select recommended action proportional to confidence.

For Validation Set synthesis, apply this additional sequence:

1. Aggregate all runs in the set.
2. Identify behaviour that remained stable and behaviour that changed.
3. Assign robustness from observed variation tolerance.
4. Assign set-level confidence from repeatability and evidence strength across runs.
5. Recommend the next action from the set-level conclusion.

# Anti-Bias Checks

Before finalising an assessment, confirm:

- Did I record what happened, not what I hoped would happen?
- Did I preserve contradictions rather than rationalise them away?
- Did I avoid assigning high confidence from a single successful run?
- Did I avoid inferring high robustness from limited scenario variation?
- Is the recommended action proportional to the confidence dimensions?

If any answer is no, revise the assessment.

---

# Relationship to Evidence Records

Evidence records should remain focused on the experiment.

Assessment logic should be referenced from this guide.

If assessment methodology changes, update this document and keep individual evidence records concise.
