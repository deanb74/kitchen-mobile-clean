# 001 - Theory of Memory

Memory is not storage. Storage preserves everything. Memory preserves significance.

Memory is the capacity to retain what should still matter later.

Memory enables continuity.

It answers questions such as:

- What is memory?
- Why do organisations forget?
- What should be remembered?
- What should be forgotten?
- How does memory degrade?

## Core Idea

Human memory, organisational memory and Digital Colleague memory all decide what survives from experience.

Without memory, there is no learning, no identity and no improvement.

Memory is selective by necessity.

If everything is remembered, nothing is distinguished.

If nothing is remembered, nothing accumulates.

## The First Memory Theorem

If everything is remembered, nothing is distinguished.

If nothing is remembered, nothing is accumulated.

Therefore memory must be selective.

## Memory and Forgetting

Forgetting is not the absence of memory.

It is the selective release of information that no longer contributes to future understanding.

Memory exists to preserve continuity between experience and future understanding.
