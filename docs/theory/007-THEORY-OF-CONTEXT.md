# 007 - Theory of Context

Context is not decoration.

Context is the surrounding circumstance that governs how experience, memory, knowledge, understanding and judgement should be interpreted.

Context does not change the information.

Context changes its interpretation.

## Core Theory

## It Explains

- Circumstances
- Perspective
- Relevance
- Interpretation
- Relationships
- Meaning
- Ambiguity

## Core Idea

Context exists alongside every stage of learning.

It determines how retained experience, organised knowledge, interpreted understanding and evaluated judgement should be applied within a particular situation.

Without context, information remains disconnected from purpose.

## Universal Properties

- Context exists alongside every stage of the theory chain.
- Context influences interpretation.
- Context determines relevance.
- Context reduces ambiguity.
- Context may change while information remains unchanged.
- Context never replaces knowledge.
- Context enables appropriate judgement.

## Derived Theorems

### First Context Theorem

The same knowledge interpreted within different contexts may produce different understanding.

### Second Context Theorem

Removing context reduces understanding without changing knowledge.

### Third Context Theorem

Context changes interpretation.

It does not change truth.

### Fourth Context Theorem

Appropriate judgement requires appropriate context.

### Fifth Context Theorem

Words do not possess fixed meaning in isolation.

Meaning is derived from context.

Understanding precedes interpretation.

---

## Practical Demonstrations

### Context Determines Meaning

The same word may refer to different meanings while remaining semantically valid in each case.

The word has not changed.

The context has changed.

Therefore the intended meaning changes.

Correct interpretation requires consideration of:

- who is speaking,
- where the interaction occurs,
- which profession is active,
- what is being discussed,
- what outcome is being sought,
- and what shared experience is already present.

Words are one component of understanding.

They are never the whole of understanding.

#### Carling and black

Customer:

"Ring through a Carling and black."

In a pub ordering context, "black" commonly refers to blackcurrant cordial.

Correct interpretation:

Carling lager with blackcurrant.

#### Tea, black

Customer:

"Ring through a tea, black."

In the same venue context, "black" commonly refers to tea without milk.

Correct interpretation:

Black tea without milk.

Observation:

- The word "black" is unchanged.
- The surrounding context differs.
- The intended meaning therefore differs.

Context changes interpretation.

It does not change truth.

### Context Determines Priority

The same facts may require different first actions depending on context.

Priority should be derived from complete situational context, not from isolated information.

### Context Determines Risk

Risk cannot be judged from words alone.

Risk should be interpreted from context, including people, environment, consequence and uncertainty.

## Implications

Context governs interpretation throughout the learning process.

It ensures that memory, knowledge, understanding and judgement remain relevant to the situation in which they are applied.

Context provides the conditions under which sound judgement becomes possible.

## Canonical Definition

Context is the surrounding circumstance that governs interpretation and relevance throughout the learning process.
