# THEORY-016-EVIDENCE

## Scope

This document records the evidence that supports Lesson as a distinct concept within Helping Hand, while preserving the distinction between theory and implementation.

## Evidence from theory

- The theory of learning defines learning as the reflective process through which experience improves future judgement by producing reusable capability.
- The theory of memory defines memory as preserving significance for later use.
- The theory of understanding defines understanding as explaining meaning within context.
- These theories leave room for a compact, reusable form of learning that is neither raw experience nor fully generalised wisdom.

## Evidence from reflection

- AJ-011 evidence records that reflection ran after a completed judgement path.
- AJ-011 evidence records that reflection captured confirmed learning, changed understanding, unresolved uncertainty, and future investigation questions.
- AJ-011 evidence records that memory was updated only for confirmed learning.
- This supports the idea that reflection can produce a durable, memory-worthy output without turning every unresolved question into a conclusion.

## Evidence from formation

- Formation gateway memory records a lesson field for each inherited stage.
- The formation recall evidence shows that lessons were later selected for recall and used to connect the earlier formation stages into a later response.
- The frozen formation evidence therefore shows that "lesson" is already a meaningful record type in the repository's operational memory.

## Evidence from architecture and philosophy

- The Understanding Lifecycle describes reflection as a step before memory and says that some understanding deserves to become memory.
- Reflection and Growth states that reflection should happen before memory and before a lesson is preserved.
- The Judgement Engine describes reflection as producing candidate learning that may return to the understanding lifecycle.
- Together these sources support the idea that a lesson is a distinct intermediate form between reflection and memory.

## Evidence assessment

The evidence supports a candidate concept of Lesson for Helping Hand.

It does not yet establish Lesson as a universal primitive in the same way that memory, knowledge, understanding or judgement are established in the existing theory library.

The strongest supported claim is this:

- A lesson is a context-bound, reusable expression of confirmed learning that can be preserved in memory and used to improve future judgement.
