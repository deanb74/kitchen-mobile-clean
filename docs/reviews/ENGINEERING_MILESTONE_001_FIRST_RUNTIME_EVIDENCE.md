## Capability Completion Rule

Every new reasoning capability is complete only when three artefacts exist:

1. Design: Why should this capability exist? (Theory and Architecture)
2. Implementation: How was it built? (Code)
3. Execution Evidence: What actually happened when it ran? (Runtime)

Compilation is required.

Behavioural evidence is decisive.
