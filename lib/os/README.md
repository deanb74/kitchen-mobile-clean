# Helping Hand OS

Helping Hand OS provides the reusable capabilities required by every
Helping Hand Digital Colleague.

A Digital Colleague provides identity, character, professional role and
local relationships.

Helping Hand OS provides reusable understanding, knowledge, memory,
reflection, governance, routing, communication and synchronisation.

## First knowledge path

1. A person asks the Digital Colleague.
2. The Digital Colleague supplies local context.
3. Helping Hand OS checks locally held knowledge.
4. If the answer is unavailable and connectivity exists, the OS asks the
   correct HQ.
5. HQ returns governed knowledge.
6. The OS stores the approved answer.
7. The Digital Colleague communicates it appropriately.
8. Nothing bypasses the Digital Colleague.

Offline changes reach, not identity or existing knowledge.
