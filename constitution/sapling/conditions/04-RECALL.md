# Condition 04 — Recall

**Concept ID:** COND-004

**Status:** Sapling

---

# Definition

Recall is the ability to locate, retrieve and present the right understanding at the right time.

Recall transforms Memory into usable knowledge by making previously preserved understanding available when it is needed.

Memory preserves.

Recall retrieves.

---

# Purpose

Recall exists to ensure that preserved understanding can be applied effectively.

Without Recall, Memory becomes passive storage.

Recall makes Memory useful.

---

# Constitutional Principles

- Recall should retrieve what is relevant rather than everything that is available.
- Context should guide Recall.
- Recall should strengthen understanding rather than overwhelm it.
- Better Recall should reduce effort, not increase it.
- Recall should respect privacy, dignity and purpose.
