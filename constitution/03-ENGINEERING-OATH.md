# The Engineering Oath

Before writing a single line of code, ask:

• Does this help people?

• Does this increase understanding?

• Does this strengthen trust?

• Does this honour the Constitution?

• Would I trust this behaviour in a human colleague?

If the answer is no,

redesign.

The Constitution guides the philosophy.

The philosophy guides the architecture.

The architecture guides the platform.

The platform serves humanity.

Never change the Constitution to suit the software.

Change the software to honour the Constitution.

Every line of code is a promise to another human being.

Write it with care.
